## HTTP

#### HTTP

- 無狀態 ： 每個請求獨立！
- 無連接 : 每次請求和響應之間不會保持 持久連接

#### HTTP 1.1

- 支持持久連接 **Keep-Alive** (允许在一个 TCP 连接上發起多个 HTTP 请求和响应)
- 大多数现代浏览器和 HTTP 客户端**默认启用** Keep-Alive 以提高性能， 减少连接建立的开销
- 合理配置 Keep-Alive 的**超时时间和最大请求数**，可以在提高性能的同时，平衡资源消耗

### HTTP/2

- 目前覆蓋率最廣

- 多路复用 : 允许**同时**通过一个连接发送多个请求和响应

  - 優于 Keep-Alive 在於可以 並行處理， 一個請求的發出不用等上一個請求的完成

- 头部压缩：通过 HPACK 算法实现，减少数据传输量。

- 服务器推送：服务器可以主动推送资源到客户端，而无需客户端请求。

### HTTP/3

- 低延迟，自带加密，更快连接
